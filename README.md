SecureShare Pro – Zero Trust Encrypted File Sharing System
 Overview

SecureShare Pro is a secure file-sharing web application designed with a zero-trust security model. It ensures that files are encrypted, access-controlled, and automatically removed after use, preventing unauthorized access and data leakage.

The system integrates encryption, authentication, secure link generation, and defensive security mechanisms, making it a practical implementation of real-world secure file-sharing systems.

🔥 Key Features
 AES-256 Encryption (CBC mode) for secure file storage
 Token-based secure links (unguessable URLs)
 Expiring links (time-based access control)
 One-time download + auto deletion (zero-trust model)
 Password protection with bcrypt hashing
 Brute-force protection (limited login attempts)
 Access logging & audit trail
 Cyber-themed UI with modern UX
